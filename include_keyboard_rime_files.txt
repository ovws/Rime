# 元书输入法：从键盘目录回写到应用目录的文件规则
# 每行一个正则表达式；以 # 开头的行会被忽略。
#
# 此列表同时保留个人数据，并同步方案运行所需资源。这样从“键盘文件”
# 更新后再重新部署时，OpenCC 的拆分、拼音和表情词表不会遗漏。

# Rime 用户词库与调频数据
.*[.]userdb.*$

# 所有 Rime 配置与方案文件（含 *.custom.yaml）
^.*[.]yaml$

# Lua 脚本与语言模型
^.*[.]lua$
^.*[.]gram$

# OpenCC 运行资源：拆分、拼音提示、表情候选等
^.*opencc/.*[.]json$
^.*opencc/.*[.]ocd2$
^.*opencc/.*[.]txt$

# 保留魔然的文本自定义短语
^.*moran_custom_phrases[.]txt$
